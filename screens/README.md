# ZIURY Mobile Screens

Screen view components representing feature modules for ZIURY Mobile v0.1 Beta (Personal Second Brain).

## Screens
- `DashboardScreen.tsx`: Daily overview, quick stats, quick capture tiles, and recent memories.
- `TimelineScreen.tsx`: Chronological stream of all life items (notes, tasks, photos, voice notes).
- `ChatScreen.tsx`: AI Chat assistant with model switcher & conversation history.
- `NotesScreen.tsx`: Markdown notes grid and instant memory search.
- `TasksScreen.tsx`: Filterable task list (Pending / Completed) with priority tags.
- `CalendarScreen.tsx`: Integrated schedule manager & event planner.
- `BudgetScreen.tsx`: Personal finance tracking income, expenses, and net balance.
- `SettingsScreen.tsx`: BYOK AI settings manager for 8 providers, API keys, and model choices.
