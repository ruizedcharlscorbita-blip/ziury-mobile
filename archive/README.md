# Archive Directory — Ziury Mobile Historical Assets

This directory serves as the static historical archive for completed version releases, audit reports, research drafts, and legacy specifications of **Ziury Mobile**.

---

## Folder Breakdown

- **`v1-reports/`**: Completed audit reports and token efficiency evaluations for Version 1.0 (e.g., `AUDIT_REPORT_v1.md`).
- **`v1-notes/`**: Raw draft ideas and initial feature brainstorming notes (e.g., `v2idea`).
- **`v1-roadmap/`**: Progress summaries and milestone achievements for Version 1.0 foundation (`V1_SUMMARY.md`).

---

## Best Practices & Conventions

1. **Read-Only Context**: Files in this directory are kept for historical context and reference. Active development guidelines reside in `docs/` and `PROJECT.md`.
2. **On-Demand Loading**: LLMs and AI subagents load archive files strictly on-demand by explicit file path reference to keep context auto-load lightweight.
