## Best Practices
- Organize prompts using lowercase kebab-case filenames.
- Save files using the `.md` or `.txt` extension.
- Use explicit inputs and expected output format in every prompt.
- Keep prompts modular — compose session context by combining `system-header.md` with task-specific additions.
