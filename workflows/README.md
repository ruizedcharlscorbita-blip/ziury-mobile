## Best Practices
- Save new workflow documents using the `.md` extension.
- List execution prerequisites and target outcomes at the top of every workflow.
- Link to relevant templates in [templates/](file:///c:/Users/Administrator/Desktop/GEMINI/projects/Ziury-mobile/templates/README.md) or reference guides in [docs/](file:///c:/Users/Administrator/Desktop/GEMINI/projects/Ziury-mobile/docs/README.md).
- Use task checklist format (`- [ ]`) so steps can be tracked inline.
