# Architectural Decision Records (ADRs)

This folder contains Architecture Decision Records (ADRs) following the lightweight Michael Nygard template. ADRs are used to capture key architectural decisions and their context.

## How to Create an ADR

1. Copy the template from `[templates/adr.md](file:///c:/Users/Administrator/Desktop/GEMINI/projects/ai%20stack/templates/adr.md)`.
2. Save it here as `XXX-short-title.md` where `XXX` is a sequential 3-digit number (e.g., `003-use-posix-shell.md`).
3. Fill out the sections: Title, Context, Decision, Status, and Consequences.
4. Run the script `bash ./scripts/knowledge-base-index.sh` to update `[INDEX.md](file:///c:/Users/Administrator/Desktop/GEMINI/projects/ai%20stack/knowledge-base/INDEX.md)`.
