# Ziury UI Components

Reusable UI components for Ziury Mobile application.

## Components
- `Header.tsx`: Brand title, model indicator badge, history drawer & settings buttons.
- `ChatMessage.tsx`: Styled chat message bubbles with role avatars & timestamps.
- `ChatInput.tsx`: Multiline message input bar & send action.
- `SettingsModal.tsx`: BYOK API Key input & active AI model selector.
- `HistoryDrawer.tsx`: Sidebar for managing & switching local SQLite conversation history.
